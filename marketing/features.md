<!-- feature-section -->
## Payflow for Craft Commerce

Add a PayPal Payflow gateway alongside the store’s other Craft Commerce gateways. Orders and transactions continue through Commerce’s established checkout, payment-source, and transaction-management patterns.
<!-- feature-section-end -->

<!-- feature-grid -->
- :icon[key] **Account credentials** Configure the partner, vendor, user, and password for the Payflow account.
- :icon[receipt-refund] **Commerce transactions** Keep payment activity attached to the order’s normal transaction history.
- :icon[shield-lock] **Server-side integration** Handle gateway communication through the Craft Commerce backend.
<!-- feature-grid-end -->

<!-- feature-section -->
## Test before launch

Use Payflow’s test environment while verifying authorisation, capture, failure, and refund behaviour, then update the gateway for the live account when the store is ready.
<!-- feature-section-end -->
