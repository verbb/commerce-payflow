PayPal Payflow adds the Payflow payment gateway to Craft Commerce. Configure the credentials for your account, take payments through Commerce’s checkout, and test the integration before switching to live transactions.

Add a PayPal Payflow gateway alongside the store’s other Craft Commerce gateways. Orders and transactions continue through Commerce’s established checkout, payment-source, and transaction-management patterns.

## Features

- **Commerce gateway:** Offer PayPal Payflow through Craft Commerce checkout.
- **Account credentials:** Configure the partner, vendor, user, and password for the Payflow account.
- **Test mode:** Exercise payments against Payflow’s test environment before launch.
- **Commerce transactions:** Keep payment activity attached to the order’s normal transaction history.
- **Server-side integration:** Handle gateway communication through the Craft Commerce backend.
- **Per-gateway setup:** Configure the gateway through Commerce alongside other payment options.
- **Test before launch:** Use Payflow’s test environment while verifying authorisation, capture, failure, and refund behaviour, then update the gateway for the live account when the store is ready.
