<h1 align="center">PayPal Payflow for Craft CMS</h1>

PayPal Payflow is a Craft CMS plugin that adds the Payflow payment gateway to Craft Commerce. Configure the credentials for your account, take payments through Commerce's checkout, and test the integration before switching to live transactions.

Add a PayPal Payflow gateway alongside the store's other Craft Commerce gateways. Orders and transactions continue through Commerce's established checkout, payment-source, and transaction-management patterns.

## Features

- Offer PayPal Payflow through Craft Commerce checkout.
- Configure the partner, vendor, user, and password for the Payflow account.
- Exercise payments against Payflow's test environment before launch.
- Keep payment activity attached to the order's normal transaction history.
- Handle gateway communication through the Craft Commerce backend.
- Configure the gateway through Commerce alongside other payment options.
